# Smart Password Generator

A Java-based utility application that generates secure passwords using user-specific information such as Name, PAN Number, and Date of Birth. The project also evaluates the generated password strength as Weak, Medium, or Strong.

This project was developed to demonstrate practical implementation of Java programming concepts including OOP, string manipulation, conditional logic, and secure password generation techniques.

---

## Features

* Accepts user details:

  * Name
  * PAN Number
  * Date of Birth

* Generates secure passwords using user data

* Evaluates password strength:

  * Weak
  * Medium
  * Strong

* Supports testing with multiple users

* Uses Java programming concepts and logical validation

---

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* SecureRandom Class
* String Handling
* Conditional Statements

## How to Run the Project

### Step 1: Compile the Program

```
bash

```

```
bash
java SmartPassword

```
